# 阶段性成果与主张边界

**中文** | [English](en/research_status.md)

更新日期：2026-08-07。

## 当前一句话结论

FE-E 已被证明能强制改变深度伴随传播形态，但尚未被证明是通用优化器；它更可能是针对
持续层深能量集中等特定异常的低频稳定器，或首先作为传播观测器使用。

## 主张矩阵

| 主张 | 当前证据 | 状态 |
|---|---|---|
| FE-E降低层间伴随粗糙度 | 解析测试、24层消融 | 支持 |
| 质量与熵项能改变能量幅值和分布 | 消融与逐步诊断 | 支持 |
| 更平滑的传播必然更快收敛 | 多个负结果 | 否定 |
| FE-E默认优于GS或AdamW | 24–192层对照 | 不支持 |
| FE-E在固定更新数下可能有较强单步作用 | 早期五种子对照 | 有限支持 |
| FE-E具有更高单位算力效率 | 双反传与墙钟结果 | 不支持 |
| GSF能恢复某些困难种子 | seed 31门控实验 | 候选信号 |
| 中层能量集中存在窄剂量窗口 | seed 47，3%/5%正结果 | 单种子候选 |
| 刚度、质量、熵可预测未来失稳 | 尚无前瞻预测实验 | 未验证 |
| 可外推至7B语言模型 | 无对应尺度证据 | 禁止外推 |

## 已完成的阶段成果

1. 数学定义修正：层索引几何、有限元一致质量、Rayleigh刚度、相对熵覆盖度。
2. PyTorch精确双反传原型、谱诊断和解析/反例单元测试。
3. 论文级Gradient Smoothing与AdamW基线。
4. Apple MLX逐步日志框架与门控状态机。
5. 24、48、96、128、192层实验；1024层主动停止审计。
6. token accuracy ≥99%连续三次的学习相变终点。
7. 同构sham observer、学习率冲击和结构传播噪声探针。
8. 英文预印本、匿名Markdown、中文文章、图表和互动网页。

## 最关键的结果

- 最新128层固定剂量实验：12个FE-E配对中3个提前、9个延后。
- 无噪声和全局能量放大环境：全部FE-E剂量更慢。
- 中层能量集中：3%提前128步，5%提前64步；仍是单种子筛选结果。
- 单次FE-E介入步约为普通步的2.24倍。
- 所有环境的平均FE-E/任务梯度余弦为负，说明它通常在抵抗任务梯度以换取规整。
- 192层seed 47同构学习率冲击中，GSF比GS-SHAM晚250步确认。

## 不应写入摘要的表述

- “FE-E解决了梯度爆炸和消失。”
- “FE-E已经优于Gradient Smoothing或AdamW。”
- “3%是最佳介入率。”
- “熵高说明信息保存得更好。”
- “短期损失斜率更陡说明模型更快学会。”
- “微型模型结果证明7B模型可获得收益。”

## 下一决策门槛

继续控制器路线之前，至少需要：

- 预注册多种子复核中层能量集中候选窗口；
- 观测指标对未来相变延迟的out-of-sample预测；
- 同构sham、运行顺序平衡和系统负载审计；
- 净墙钟收益超过诊断与双反传成本；
- 在至少一个更接近语言建模的任务上复现。

任一项失败，都应优先保留观测器研究价值，而不是继续提高门控复杂度。
